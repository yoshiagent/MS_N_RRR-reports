RSR 相對強度輪動 — 策略與用法
🔁 什麼是 RR
Relative Rotation（相對輪動）— 簡版。
兩檔股票皆中長期多頭，但因產業節奏錯開，相對強弱呈現可辨識的振盪。
系統在「兩檔皆漲、輪流領先」中切換資金。
📊 RS / Z60 計算
RS = ln(A / B)　A 相對 B 的對數比率
Z60 = (RS − MA60) / SD60　60 日滾動標準化

Z60 反映「當前 RS 偏離歷史均值的程度」。
✅ 觸發：RS_MA20 穿越
RS 由下往上穿越 MA20 → switch_to_A（買強者）
RS 由上往下穿越 MA20 → switch_to_B

簡版觸發較快、訊號較多，但
不等折返，可能在極端點才換股。
⚙ 動態 Z 門檻
依市場狀態自動調整：
強多 + 站上週MA20 → 2.5（嚴）
中性 / 中多 → 2.0
中空以下 → 1.5（寬）
🎯 用法建議
RR 簡版適合短中波段切換，
訊號多但雜訊也多，建議：
① 先看主頁市場結構，confidence ≥ 70 才考慮
② 兩檔皆需週 MA20 向上
③ 若想等更穩定的訊號，看 RRR 嚴格版
⚖ RR vs RRR 差異
　RR 簡版RRR 嚴格版
觸發RS_MA20 穿越Z60 折返
訊號數多少
勝率中高
適用短中波段中長波段
