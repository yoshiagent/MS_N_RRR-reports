選股邏輯（兩層時序）
⓪ 股價門檻：月收盤 > 50 元才入選（低價股不列）。
① 每月月底 → M 股池（安全名單）：月 K MACD(12,26,9) 綠柱縮短（OSC < 0 且 > 上月＝負值收斂）＋ 股價站穩月 MA20（月收盤 ≥ 20 月均線）。
→ 目的：圈出「長期大資金進駐」的安全名單——月線賣壓衰竭、價格已被承接到長期均線之上。
② 每週五 → 進攻名單：於 M 股池內篩 週 K MACD 翻紅/金叉（OSC 由負轉正＝DIF 上穿訊號線，兩者為同一事件）＋ 本週成交量 > 20 週均量。
→ 目的：確認 M 股池中哪幾檔「這週主力開始發起進攻」。
執行時序（何時更新）
判定一律用資料日 as_of（價格庫最新交易日），非牆上時鐘：
· 月：as_of ≥ 該月最後日曆日 → 該月完成 → 當晚重圈 M 股池（月底遇假日 → 次月首個交易日資料到後自動補圈）。M 股池整月凍結，週篩只在池內進行。
· 週：取 ≤ as_of 的最近週五為週標籤；週五晚間資料更新後即為當週，非週五期間顯示最近完成週的進攻名單（確定性重算，結果不漂移；週五逢假日 → 下週一晚間補判）。
名詞（Glossary）
MACD(12,26,9)＝DIF（12 月/週 EMA − 26 月/週 EMA）與訊號線（DIF 的 9 期 EMA）；OSC（柱狀體，Oscillator）＝DIF − 訊號線。EMA 口徑 adjust=False，與 XQ/XS 一致。
綠柱縮短＝OSC 為負但絕對值逐月縮小（賣壓衰竭）；綠柱連縮 n 月＝連續滿足縮短的月數。
翻紅/金叉＝OSC 由 ≤0 轉 >0 ⟺ DIF 上穿訊號線（同一事件的兩種說法）。
20 週均量＝週成交量 20 週滾動平均（含本週）；量比＝本週量 ÷ 20 週均量。
月 MA20＝20 個月移動平均線（月線圖上的 MA20）。

📜 XS 選股腳本 — 月篩（M 股池·頻率設月）（XQ 可直接複製 — 點開）
// 月週候選股 — 月篩（M 股池）
// 頻率：月　｜　用途：XQ 選股腳本（與 MS_N_RRR mw_candidate 月篩同口徑）
// 條件：股價 > 50 ＋ 月 K MACD(12,26,9) OSC 綠柱縮短（負值收斂）＋ 收盤站穩 20 月均線
input: fastlen(12), slowlen(26), siglen(9), malen(20), pricefloor(50);

value1 = xaverage(close, fastlen) - xaverage(close, slowlen);   // DIF
value2 = xaverage(value1, siglen);                              // MACD（訊號線）
value3 = value1 - value2;                                       // OSC（柱狀體）

if close > pricefloor                                           // 股價門檻：> 50 元
   and value3 < 0 and value3 > value3[1]                        // 綠柱縮短：仍為負、但較上月收斂
   and close >= average(close, malen)                           // 站穩月 MA20（20 月均線）
then ret = 1;

// 月週候選股 — 週篩（進攻名單；於 M 股池成員內使用）
// 頻率：週　｜　用途：XQ 選股腳本（與 MS_N_RRR mw_candidate 週篩同口徑）
// 條件：週 K MACD(12,26,9) OSC 翻紅（=DIF 上穿訊號線的金叉）＋ 本週量 > 20 週均量
input: fastlen(12), slowlen(26), siglen(9), vlen(20);

value1 = xaverage(close, fastlen) - xaverage(close, slowlen);   // DIF
value2 = xaverage(value1, siglen);                              // MACD（訊號線）
value3 = value1 - value2;                                       // OSC（柱狀體）

if value3 > 0 and value3[1] <= 0                                // OSC 由負轉正 = 翻紅/金叉
   and volume > average(volume, vlen)                           // 本週量 > 20 週均量
then ret = 1;
